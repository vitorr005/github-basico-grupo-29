
# Nosso primeiro trabalho colaborativo no GitHub

## Objetivo
Esta atividade tem como objetivo demonstrar como diferentes integrantes podem trabalhar juntos em um mesmo repositório utilizando o GitHub.

## Como funciona a colaboração?

Cada integrante poderá acessar os arquivos, realizar alterações e registrar suas contribuições por meio de commits.

## Registro das contribuições

### Integrante 1
- Dica: Utilize o README.md para apresentar o objetivo e as informações principais do projeto.

### Integrante 2
- Dica: Utilize commits com mensagens claras para identificar as alterações realizadas.

### Integrante 3
- Dica: Consulte o histórico de commits para acompanhar as modificações feitas no projeto.
