
# Cartilha Digital: GitHub para Iniciantes

## 1. Apresentação

Esta cartilha foi desenvolvida com o objetivo de apresentar os conceitos básicos do GitHub para pessoas que estão começando na área de tecnologia.

O material aborda desde a criação de um repositório até o compartilhamento e a colaboração em projetos.

**Público-alvo:** estudantes e iniciantes em programação.

## 2. Introdução ao Git e GitHub

### O que é Git?

Git é um sistema de controle de versão que permite acompanhar as alterações realizadas nos arquivos de um projeto.

### O que é GitHub?

GitHub é uma plataforma online que utiliza o Git para armazenar projetos, organizar arquivos e permitir que diferentes pessoas trabalhem juntas.

### Qual é a diferença entre Git e GitHub?

O Git é a ferramenta responsável pelo controle de versões, enquanto o GitHub é uma plataforma que permite hospedar repositórios e facilitar a colaboração.

### O que é um repositório?

Um repositório é o espaço onde ficam armazenados os arquivos e o histórico de alterações de um projeto.

Existem dois tipos principais:

- **Público:** qualquer pessoa pode visualizar o conteúdo.
- **Privado:** somente o proprietário e as pessoas autorizadas podem acessar.

## 3. Primeiros passos

### Como criar uma conta?

1. Acesse https://github.com.
2. Clique em Sign up.
3. Informe seu e-mail e crie uma senha.
4. Siga as etapas de cadastro.
5. Confirme sua conta.

### Como criar um repositório?

1. Entre na sua conta.
2. Clique em New.
3. Escolha um nome para o repositório.
4. Defina se será público ou privado.
5. Marque a opção Add a README file.
6. Clique em Create repository.

### O que é README?

O README é um arquivo utilizado para apresentar o projeto, explicar sua finalidade e fornecer informações importantes para quem acessa o repositório.

## 4. Arquivos e versões

### O que é Markdown?

Markdown é uma linguagem de marcação simples utilizada para formatar textos, títulos, listas e links em arquivos com extensão .md.

### O que é commit?

Commit é o registro de uma alteração realizada no projeto. Cada commit possui uma mensagem que descreve o que foi modificado.

### O que é histórico de alterações?

É o registro dos commits realizados, permitindo identificar quem fez cada alteração e quando ela aconteceu.

## 5. Colaboração

### O que é branch?

Branch significa ramificação. É uma linha independente de desenvolvimento que permite trabalhar em alterações sem modificar diretamente a versão principal do projeto.

### O que é Pull Request?

Pull Request é uma solicitação para que as alterações feitas em uma branch sejam revisadas antes de serem incorporadas à branch principal.

### O que é Merge?

Merge é o processo de juntar as alterações de uma branch a outra.

### Como compartilhar um repositório?

1. Acesse o repositório.
2. Entre em Settings.
3. Clique em Collaborators.
4. Selecione Add people.
5. Pesquise o usuário do GitHub.
6. Envie o convite.

**Atenção:** nunca compartilhe sua senha ou códigos de autenticação.

## 6. Prática e reflexão

### Desafio para o leitor

Crie um repositório para organizar seus estudos.

1. Escreva um README apresentando seu objetivo.
2. Adicione três assuntos que deseja aprender.
3. Crie um arquivo de anotações.
4. Faça uma alteração e registre um commit.
5. Compartilhe o repositório com um colega.

### Como conferir se conseguiu?

- O repositório foi criado corretamente.
- O README apresenta seu objetivo.
- O arquivo de anotações está disponível.
- O commit aparece no histórico.
- O colega consegue acessar o repositório.
