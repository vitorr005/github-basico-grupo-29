
# GitHub Básico

## Sobre o projeto
Este projeto tem como objetivo apresentar os conceitos básicos do GitHub, ensinando iniciantes a criar repositórios, organizar arquivos e colaborar em projetos.

## Objetivo
Desenvolver uma cartilha digital com explicações simples e exemplos práticos sobre o GitHub.

## Conteúdo
- Introdução ao Git e GitHub
- Repositórios públicos e privados
- README e Markdown
- Commits e histórico de alterações
- Branch, Pull Request e Merge
